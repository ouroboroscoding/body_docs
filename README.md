# body_docs
[![pypi version](https://img.shields.io/pypi/v/body_docs.svg)](https://pypi.org/project/body_docs) ![Custom License](https://img.shields.io/pypi/l/body_docs.svg)

## Install

```bash
pip install body_docs
```

## CLI

| argument | expects | default | description |
| -------- | ------- | ------- | ----------- |
| -f, --format | html \| markdown | markdown | The format to out the documentation in |
| -o, --output | directory | ./ | The folder to store generated documentation in |
| -p, --parser | google | google | The docstring format |
